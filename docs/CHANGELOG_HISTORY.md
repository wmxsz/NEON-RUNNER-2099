## v2.9.0-G — 统一审计修复与回归升级

- **DDA 类型契约：**将 DDA 开关布尔值与实际难度模式字符串彻底分离，避免 `compute_dda()` 的 String 返回值落入 Bool 变量，并统一传给 `Spawner` 与 `Game.start_run()`。
- **输入回放 schema 2：**记录 `dda_enabled`、`dda_mode`、游戏版本、引擎版本、物理 tick rate 和规则集版本；跨构建或不兼容记录将拒绝精确回放，不再把布尔值当作难度模式。
- **道具安全投放：**在三车道和多个纵深位置做有限候选搜索；所有候选受阻时跳过此次投放，最后一次写入前再次检查碰撞间隔。
- **音频混音：**分离 Music、SFX、UI 总线，效果按类型复用/补齐；Master 硬限幅器保持在效果链末端；音效池改用优先级抢占，降低普通芯片/动作音效切掉死亡、BOSS、复活提示的风险。
- **存档事务：**关键跑局统计、任务完成、复活、超频、BOSS 奖励先快照状态；持久化失败时回滚内存状态。任务完成信号延后到存档成功后发出。
- **输入队列：**队列溢出加入计数，优先移除车道微调，而不是无提示地删除重要跳跃/滑铲操作。
- **模块边界：**Telemetry 通过 `configure_targets()` 接线，并通过 `Effects.apply_perf_profile()` 调整粒子预算，不再从遥测模块直接读写 Effects 私有粒子节点。
- **进度事件热点：**跳跃/滑铲进度事件先筛出当前可更新的任务；只有命中有效任务时才创建窄事务快照，避免每次动作复制全部统计、设置、皮肤和最近对局数组。
- **统一离线入口：**`sh tools/run_offline_checks.sh` 现在执行模型/资源、模式目录、旧回归契约和 v2.9 新契约；如果系统安装了 Godot，也会额外运行 headless 导入和主场景冒烟测试。

### 验收边界

离线检查可证明这些源码契约与资源结构保持一致，但不替代 Godot 语义编译、音频听感、物理可解性证明或 Android 真机性能测量。本环境未安装 Godot/ADB，故相应引擎与设备检查会明确报告为 SKIP。


## 2.8.1-G — 音乐与音效响度升级

当前基线：Godot `2.8.1-G`，Android `versionName=2.8.1-G` / `versionCode=23`。

- `GameMix` 压缩器改为较温和的 `-9 dB / 2.5:1`，增加 `+3 dB` makeup gain，让音乐与音效整体更容易听清。
- 按 WAV 实测峰值对 12 类短音效设置不同补偿，特别提升 UI、成就与开局 Ready 提示；用户的 0–100% 音效滑块依然有效，音量为 0 时仍静音。
- 添加 `AudioEffectHardLimiter`，混音输出 ceiling 设为 `-1 dBFS`，降低多个音源重叠时产生削波失真的风险。
- 为已播放音效跟踪类型，音量滑块改变时仍能正确保留各音效增益差。
- 离线检查新增增益参数、安静音效补偿与硬限制器契约；9 首 OGG 和 12 个 WAV 将从最终干净解压副本做全轨解码。

### 验收边界

根据原始 WAV 测量值和压缩器 transfer curve 估算，短音效的峰值输出相比旧混音路径预计提高约 `+4.5 至 +7 dB`（依音效类型而异）；音乐平均响度预计提高约 `+3 dB`。这些是静态估算，未经过 Godot 音频总线录音、扬声器测量或 Android 实机听测；限幅器会在混合峰值接近上限时自动衰减。

- 遥测开关同时清除连续慢帧降档计数，避免关闭/重开性能 HUD 时沿用旧的劣化窗口。
- 音量滑块无 debounce 定时器：缓慢拖动也只会预览，只有 drag end/focus exit 才进行一次存档提交。
- 扩展配置接线、存档、回放、Android 安全区和 CanvasLayer 顺序的离线源码契约；修正校验器的版本基线与历史名称误报。
- Android Auto Backup 已显式启用；当前仅导出 arm64-v8a，发布签名字段保持空白。正式 APK 需在配置好的 Godot/Android 环境导出并安装验证。

## v2.4.0-G — 输入健壮性、热循环与移动 Shader 优化

基线：`v2.3.0-G`，Android `versionCode=17`。当前源码与 Android 导出版本递增到 `2.4.0-G` / `18`。

- 触屏系统改为绑定单一触点 index，记录手势开始时是否处于可输入状态；多点触控不会相互覆盖手势，状态切换会清除旧手势，避免旧触控结束事件污染新局。
- `Main` 统一通过 `Input.set_enabled()` 启停输入，让切换状态时的队列与触摸手势一起复位。
- `Spawner.check()` 复用 `HitResult`，避免每个 60Hz 碰撞检查都分配一个结果对象；该返回值属于借用对象，调用方应在下一次 `check()` 前同步消费。
- 移除仓库内无消费者、却每帧从 `Game.tick()` 广播的 `score_updated` 信号。HUD 本来就由 Main 读取 Game 当前状态更新。
- FPS/渲染遥测改为跟随“显示 FPS”设置启停。隐藏时不再每半秒采样 RenderingServer；重新启用时清空旧采样窗口。
- 楼宇窗格 Shader 将多次调用的 `sin(dot())` 哈希改成多项式哈希，目标是减少移动端逐像素开销；实际帧时间变化必须在设备上测量。
- 移除没有 UI、没有运行效果的 `quality` 设置字段，避免存档保存一项不会生效的偏好。
- MultiMesh 池的隐藏槽只在活跃状态切换时写入零变换；障碍实例色只在对象样式变化时写入；零件静态 Euler 方向在初始化阶段预计算，减少每帧矩阵基底计算与渲染服务器写入。
- HUD 道具计时标签按道具类型缓存，倒计时只在显示秒数变化时更新文字；新局只隐藏与清理显示状态，不销毁并重建标签节点。
- 修正道具渲染池的未定义 kind-list 标识，使用稳定的 `POWERUP_KINDS` 索引映射；离线契约增加检查，防止再次出现。
- 城市建筑装饰的 MultiMesh 世界变换不再在普通移动时整套重算：只有建筑回收到新尺寸/布局时才重建全部装饰，日常移动仅平移激活装饰实例的 Z 坐标。
- 多个激光障碍共享同一发光材质时，每帧仅更新一次脉冲颜色，避免每个激光实例重复写入同一材质。
- 速度线粒子的 emitting 状态与两档透明度材质采用状态边沿缓存，仅在普通/超频模式改变时更新；`reset_fx()` 同步复位缓存与材质值，避免跨局状态不同步。
- HUD 的分数/距离整数显示、芯片数和连击提示增加显示值缓存；只有文本或显隐状态发生变化时才修改 Label，减少重复格式化与 CanvasItem 属性写入。
- 扩展离线校验器，检查上述源码契约并同步 Godot/Android 版本号。

Godot 语义编译、真实场景渲染和 Android 真机仍需在 Godot 4.7.x 环境验收；本地模型预览不等同于引擎画面。
