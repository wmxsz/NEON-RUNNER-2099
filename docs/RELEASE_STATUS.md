# 当前交付状态

> 当前开发基线：v4.3.0-G（Android versionCode=39）。

## 本版回放/测试隔离、移动端输入恢复与实体跑道细节升级（v4.3.0-G）

- 回放采用临时文件写入、flush、JSON 回读与结构校验后再替换主文件；保留上一份有效记录，并在主文件无效时尝试恢复。测试脚本会强制启用 `NR2099_TEST_MODE=1`，存档和回放使用独立路径，清理测试工件不再触碰玩家正式存档。
- Android/iOS/桌面失焦及移动端暂停时清理活动触点与输入队列，避免应用切后台后缺失 touch-up 事件导致恢复时误跳/误操作。
- 道路加入原生 `MultiMesh` 机械横肋和钛合金紧固件，覆盖 88 组横肋及 528 个紧固件，关闭投影，仅增加两个共享材质绘制调用；沿用道路 42m 滚动周期以同步视觉运动。
- 新增回放主文件损坏后备份恢复的运行时回归，以及输入失焦取消手势的回归。静态检查不等价于 Godot 语义编译或真机性能测试。

## 归档升级：原生渲染预算分层与赛博跑道抗闪烁（v4.2.0-G）

- 高档使用原生 DirectionalLight3D 四分区阴影，60m 覆盖距离与平滑分区过渡；中档采用双分区、42m 距离；低档关闭方向光阴影并使用低成本正交模式配置。
- Environment 辉光按实际层数分档：高档最多五层、中档三层、低档常态零层；低档超频临时恢复两层，结束后自动返回低档预算。
- 赛博跑道的机械接缝、刻线、能量导轨和同步条使用 `fwidth()` 屏幕空间抗闪烁覆盖率；没有新增纹理读取，保留原生 4× MSAA 与 3D 比例 1.0。
- Telemetry 增加实际生效的阴影与辉光预算快照；机制测试覆盖高/中/低三档和低档超频回退，离线合同保护其接线。
- 当前离线检查与干净 ZIP 复验完成。Godot 4.7.2-stable 实际语义编译、Shader 导入/渲染以及 Android FPS/p95/温度仍未运行。

## 本版原生赛博天空与测试可信度升级（v4.0.0-G）

- 把纯色背景升级为 Godot 原生 `Sky`/`ProceduralSkyMaterial` 的深蓝—紫红—冷青多段天空；天空保持静态，环境辐射图固定 128×128 并增量生成，避免章节渐变持续触发辐射缓存更新。
- 章节气氛继续由雾、环境光、赛道网格、建筑电力脊线与霓虹材质承担，保留现有赛博场景美术与 60Hz 固定模拟。
- 修复 headless 测试的协程等待问题，消除 `or true` 弱断言，增加原生天空运行合同测试；内容长跑测试具有独立 5400 帧预算，测试以固定 60 FPS 调度。
- 静态合同、PBR/模型/UI 资源和最终 ZIP 干净解压门禁通过。Godot 4.7.2-stable 不在当前环境，真实语义编译、着色器导入与 Android FPS/p95 尚未运行。

## 归档基线：v3.9.0-G 平滑相机冲击反馈与可调震动

- 相机跟随基线独立于渲染震动：基础位置使用帧率无关阻尼，最终位置叠加连续多频冲击波形与平滑包络，去除每帧随机跳点及反馈污染。
- 设置新增 `cameraShake`（0–100%，默认 75%），使用原生 HSlider；支持实时预览、结束提交和保存失败回滚。存档值仅接受有限数字并夹制到 `[0,1]`，旧存档由默认设置迁移。
- 大帧间隔的相机积分限制为 50ms，减轻从暂停/后台恢复或慢帧时冲击效果瞬时丢失的问题；不改跑酷物理/回放确定性，不增加全屏后处理。
- 离线发布合同验证相机基线、震动包络、设置校验/接线与随机偏移移除。Godot 引擎语义编译、真实画面与设备帧率尚未运行。

## 归档基线：原生细节法线与触屏设置体验（v3.8.0-G）



- 装甲 micro-normal 迁移到 `StandardMaterial3D.detail_normal`，保留源材质基础法线；用受控法线振幅、RGBA 细节遮罩和回归统计保护大面配色及刻线细节。
- 设置滑块、开关和滚动条继续使用 Godot 原生 HSlider/CheckButton/ScrollContainer，但通过主题 StyleBox 与项目自带 SVG 图标统一赛博外观；设置项标签可直接点击，触控行高度不低于 48 逻辑像素。
- 二级面板遮罩支持鼠标与触屏空白处关闭；Esc/P/Android 系统返回按模态优先栈执行，避免设置面板后方的跑局意外继续；返回主页图标已纠正。新增 SVG 资产后，发布清单库存为 12 个图标。
- **当前验证边界：**离线检查和干净包复验通过；当前容器无法访问外网下载目标 Godot，因此引擎编译/导入、运行截图、APK 与 Android 设备帧率尚未实测。源码结构通过不等于实机无 Bug。

## 归档基线：赛博材质与原生矢量 UI 精修（v3.7.0-G）

- **装甲和跑道贴图：**扩大装甲宏单元、细化边框/接口/数据刻线，减少密集蜂窝纹理的壁纸感；降低跑道广域噪声，让装甲分区与电路保持视觉主次。横向/纵向周期接缝已加入严格回归阈值。
- **核心 UI 图标统一：**暂停、超频、芯片、商店、任务、成就、设置、主页和启动按钮统一采用内置 SVG；Button 仍由 Godot 原生 Control 与 StyleBox 管理。核心 HUD/菜单不再依赖 Unicode 符号的系统字体替代行为。
- **原生测试入口：**`tools/run_godot_tests.sh` 在正确的 Godot 4.7.2-stable 可用时运行编辑器导入/解析、4 个自动测试场景和主场景启动烟雾测试，并拒绝把错误补丁版本当成发布验证。

## 延续的基线：v3.5.0-G 原生功能与插值审计

- 已开启 Godot 原生物理插值，并为玩家复位、远/近景回收根、地标/飞行器/标牌/拱门循环、效果池传送和 MultiMesh 活动槽位增加对应重置，避免物体从旧位置插值到新位置造成拖影。二次检查补齐建筑顶部/天线/屋顶附属槽位及初次入树位置的复位。
- 跑道 `scroll` 和建筑窗格 `time_` 属于 Shader uniform，不能指望 Node 插值自动处理；当前使用 Godot 原生 `Engine.get_physics_interpolation_fraction()` 在渲染帧内插值，暂停/结算状态冻结。
- 常态不再执行自制全屏锐化/调色层；原生 Environment 负责 Filmic、fog、glow、ambient，原生 MSAA/过滤负责边缘与纹理细节。屏幕采样只用于高速/超频色差强调。
- HUD 和菜单已经使用原生 CanvasLayer/Control/StyleBox；音乐/SFX 使用 Godot 音频总线、AudioStreamPlayer 与效果链；程序化城市和重复障碍采用原生 MultiMesh/GPUParticles，不重复造轮子。
- 本版没有把“原生化”理解为删除赛博定制；道路能量线路、建筑数据脊线、能量拱门和装甲仍由专用 PBR/Shader/GLB 负责。离线检查不能证明实际视觉、编译或帧率。


## 本版原生材质层与颜色保真升级（v3.6.0-G）

- **原生 PBR detail overlay：**玩家、障碍/道具外壳、城市材质和导入 GLB 使用 `StandardMaterial3D.detail_enabled`、`detail_albedo` 与 `BLEND_MODE_MUL`，而非把装甲贴图替换成主 Albedo。材质自身的颜色因子、顶点色和阵营/章节色保留；普通法线/粗糙度通道继续使用各自纹理及原有 strength 设置。
- **RGBA 局部遮罩：**`cyber_armor_albedo.png` 改为 1024×1024 RGBA；Alpha 仅在六角密封边、机械接缝、蚀刻线路和嵌入式数据刻纹处混合细节。未遮罩大面均值约 RGB 251.6/252.7/254.4，遮罩覆盖率约 22.5%，减少整块装甲被乘暗的情况。
- **清理冗余占位采样：**检查 9 个 GLB 的 53 个导入纹理 sidecar，均为 2×2 纯白 UV 占位图。运行时仅当贴图尺寸为 2×2 且来源位于 `res://assets/models/` 时移除这类底色纹理；真实贴图路径不会被无条件清空。
- **新增护栏：**离线校验会验证所有 GLB 侧车图仍是可预期的纯白占位图、Alpha 遮罩不是全空或过度铺满、未遮罩大面足够接近白色，以及 player/spawner/world 全部走原生 MUL detail 层。`validate_visual_assets.py` 的大图统计改用 float64，避免 float32 聚合出现超出 0–255 的不可能均值。

## 本版已完成的源码与资源升级

- v3.4.0-G 纠正了道路美术方向：赛道采用赛博未来能量跑道设计。新版 `cyber_deck_*` PBR 增加双层精密边框、四点数据锁、遥测刻线、模块倒角与抛光导能区，并提高装甲板本体可读性；道路 Shader 使用分区金属度与青/洋红双谱轨道。
- 机甲/载具用 `cyber_armor_*` 调整为近中性高亮微表面，让 GLB 本身的阵营颜色不再被过暗贴图压制；双切面六角单元及嵌入式遥测线增强精密科技感。数据拱门升级为薄主环、双能量导管及批处理信号刻度。
- 玩家程序化装配仍保留肩甲、分层胸甲、反应堆核心、背部双推进器与六种轮廓皮肤；同一套细节贴图在玩家和 GLB 载具上采用各自适合的 UV 比例，发光材质不被非发光微表面覆盖。
- 城市楼宇窗格着色器新增分段电力脊线/冠部信号轨迹，复用 MultiMesh 实例变化参数，没有新增纹理读取或实时灯光节点。
- 保留原生 3D 渲染比例 1.0、默认 4× MSAA、16× 各向异性过滤和道路两次材质采样。城市回收队列、活跃特效池、帧预算和 Bloom 策略沿用 v3.3 基线，不声称它们的 FPS 收益已由真机测量。
- 所有活跃资源引用、导入 sidecar、版本元数据、资源生成器、验证器与美术流程文档已同步到 `3.6.0-G` / Android `versionCode=32`。当前逐项报告见 [`audit/archive/V3_6_0_CLEAN_HANDOFF.md`](audit/archive/V3_6_0_CLEAN_HANDOFF.md)。
