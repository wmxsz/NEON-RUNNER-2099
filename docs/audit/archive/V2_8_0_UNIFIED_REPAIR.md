## 状态说明

- **已修复（源码/静态证据）**：实现和离线契约已更新，但仍不等于运行时验证。

## 本版静态验证覆盖

- GLB/PBR 资产结构、UV、非有限值与资源引用。
- 9 个 OGG 与 12 个 WAV 的存在、格式/波形载荷及离线解码。
- GDScript 引号/括号平衡和空白策略（不是 GDScript 解析器）。
- 随机种子参考向量、输入轨迹 schema、关卡模式结构、核心状态生命周期。
- 存档签名/回滚入口、音量滑块提交时机、PostFX/UI 层级、安全区和配置引用契约。
- Markdown 本地链接、版本号和 Android 导出字段一致性。

## 必须在目标环境完成的最终验收

1. Godot 4.7.x 执行 headless editor 导入/语义检查并运行主场景，保存完整错误日志。
2. 连续重开 20 局、复活、暂停/后台切换、音频章节/BOSS/超频切换与异常存档恢复测试。
3. 在代表性 Android 真机记录平均帧时、P95、慢帧率、内存、温度、长时间稳定性；比较预加载前后的启动与内存成本。
4. 构建 debug APK 实际安装运行；配置私有 release keystore 后再做 release 导出与签名检查。
5. 用 Godot 相同版本回放保存的输入轨迹，验证输入帧与最终事件一致；未实现全物理状态快照，所以不承诺跨设备 bit-exact 确定性。
