# v2.5.0-G 升级记录：章节音乐预载与性能 HUD 事件化

## 基线与范围

- 上一版本：v2.4.0-G，Android versionCode 18。
- 当前版本：v2.5.0-G，Android versionCode 19。
- 范围：音频资源引用路径、性能遥测 HUD 更新方式、离线回归契约与维护文档。

## 已实施升级

### 章节音乐预载

`systems/audio.gd` 现在通过 `MUSIC_STREAMS` 固定预载八首章节曲与一首 BOSS 曲。播放时按索引读取资源，不再在章节转换路径中动态构造 `res://` 路径并执行 `load()`。预载列表与 `MUSIC_TRACKS` 顺序一一对应，离线校验器确认九条资源路径唯一且实际存在。

预期收益是减少第一次进入新章节/BOSS 曲时的同步资源查找与载入工作。代价是更多音频资源在启动时即建立资源对象；实际启动时间与常驻内存变化尚未在 Android 设备测量，因此暂不声称具体性能提升。

### 性能 HUD 事件化

`ui/hud.gd` 现在监听 `Telemetry.report_updated`，由 Telemetry 每 0.5 秒采样后推动性能文本更新。HUD 保存最后一条显示字符串，仅在内容变化时写入 Label。每帧 `_process()` 不再执行遥测文本格式化。

这会减少开启 FPS 显示时的字符串构建与 UI 属性写入频率，但不改变 Telemetry 的采样频率或游戏规则。

### 回归检查与文档

- 离线校验器要求九首 OGG 都出现在预载列表，并拒绝音频切换路径恢复为动态 `load()`。
- 校验器确认 HUD 通过遥测信号更新，且 `_process()` 不再轮询/格式化遥测行。
- README、变更日志、导航与回归清单已同步到 v2.5.0-G / Android versionCode 19。

## 当前验证边界

离线资源/源码契约检查与 Python 工具语法检查可执行；它们不是 Godot GDScript 语义编译。此环境没有可用 Godot 4.7.x 可执行文件，因而本轮未完成场景/Shader 导入编译、真实章节切歌、冷启动内存测量或 Android 真机性能测试。

后续全维度静态审计单独保存在交付目录的 `FULL_STATIC_AUDIT.md`，其中列出的发现不会在本轮继续混入修复，以便下一轮统一处理。
