# v2.1.0-G 深度静态审计报告

日期：2026-10-16  
审计基线：用户上传的 `v2.0.0-G` 源码及前轮修正版；本轮更新为 `2.1.0-G`。

## 本轮继续发现并修改

随机状态修正依据：[Godot 官方 GDScript lambda 说明](https://docs.godotengine.org/zh-cn/4.x/tutorials/scripting/gdscript/gdscript_basics.html)指出局部变量在 lambda 创建时按值捕获，数组/字典等引用类型的内容更改则可共享。实际项目仍需在目标 Godot 4.7 环境运行确认。

1. **音频播放路径整顿：**原音频脚本留有未用于真实 BGM 的实时合成器，且 SFX 合成共享单一振荡器，快速连续事件可能相互覆盖。现在 BGM 使用 9 首 OGG，12 个短音效使用预生成 WAV 和固定 8 voice 播放池，保留原有音频公共调用和音乐锁接口。真实声音品质/延迟尚待听测。
2. **随机局可复现：**每局 seed 同步到 Game/Spawner；玩法生成器的模式选择、道具决策、随机车道与 BOSS 编队使用 seeded RNG；reset 清空上局模式缓存。继续审查时发现，Godot GDScript lambda 对标量局部变量按值捕获，因此随机状态若通过 `s = ...` 重新赋值，不能依赖其在多次调用间推进；现在将状态放在共享引用类型数组中，通过 `state[0]` 变更；随后进一步发现原混合公式并非标准 Mulberry32，已校准为标准 JS 参考算法，并用 16 位拆乘实现 32 位模乘，避免大整数乘法依赖溢出行为。固定 seed 的 5 项参考向量护栏检查序列。Game Over 数据包括 seed，可用于后续回放/复现。这里只能保证随机源接线，不能替代引擎里的完整对局回放。
3. **存档 guard 安全性：**在签名计算之前校验签名字段类型、数值字段的数值类型、有限性和上限，避免损坏/异常值在验证阶段触发转换问题；其余未知皮肤/成就/任务 ID、设置范围与存档数组继续按白名单规范化。
4. **设置 schema 与版本同步：**默认设置包含 `hdr`；项目和 Android 标识更新为 `2.1.0-G`，`versionCode=15`。
5. **回归检查增强：**检查所有字面 `play_sfx` 调用的名称都出现在音效映射中，验证 WAV 格式及时间范围；检查玩法随机路径不再调用全局随机方法；增加 GDScript 字符串、注释和括号词法结构扫描。

## 保留的高影响玩法修复

- 车道目标引导：当前 60Hz 数值模拟单次换道约 300ms 横移 1.79m；按实时配置推导的低障碍脱离需要约 1.37m。模拟了单次换道、快速反向、边缘重复输入和冰面低阻尼收敛。
- 输入队列：相邻同方向车道输入成组合并，包含连续三次及以上输入。
- 滑铲/闪避：统计只在真实起滑时递增，并要求障碍实际与玩家所在车道横向碰撞范围重叠。
- 高速障碍：950m 模式的 `dz=0` 全道无人机先到，`dz=10` 全道低障碍后到；校验器同时锁定放置和移动方向。
- 固定步长热循环：移除丢弃的临时 HitResult，复用特效信息字典和道具计时器键表。
- UI 回调：购买、装备与任务领取显式固定皮肤/任务 ID。

## 离线审计结果

- **模型：**9 个 GLB，网格、三角形索引、有限顶点、UV 范围及材质检查通过。
- **材质：**6 张 1024×1024 PBR 贴图，通道/像素有限性及接缝比检查通过；本轮观测最高接缝比约 1.04，检查阈值为 2.25。
- **资源：**46 处字面 `res://` 引用无缺失；30 个导入 UID 唯一，sidecar 引用源文件均存在。
- **音频：**9 首 OGG 均通过 `ffprobe` 元数据读取及 `ffmpeg` 全轨解码（Vorbis、44.1kHz、立体声，约 52.2–69.6s）；12 个 WAV 均为 mono / 16-bit PCM / 44.1kHz，时长范围 0.06–0.56s；生成工具重复执行后音效文件 SHA-256 不变，音效峰值检查未发现削波。
- **设置/存档：**已检查默认 `hdr` schema、数值和类型防护、已知 ID 白名单和任务集合完整性。
- **版本：**`project.godot` 与 Android export preset 均为 `2.1.0-G`，`versionCode=15`。
- **源码契约：**车道控制模型、边界防护、滑铲统计、950m 到达顺序、主循环重复分配护栏、SFX 名称映射、共享数组 RNG 状态、标准 Mulberry32 参考向量与结算携带 seed 均通过。
- **词法扫描：**16 个 GDScript 文件的引号、字符串、注释与 `()[]{}` 配对检查通过；所有 Python 工具通过 `py_compile`。

离线命令：

```bash
python3 -m py_compile tools/*.py
python3 tools/validate_visual_assets.py
```

## 无法从静态检查推出的结论

当前环境没有 Godot 可执行文件、`adb` 或已配置的 Android 导出环境。因此没有实际执行：

- Godot 4.7 的资源导入、GDScript 语义编译、Shader 编译与主场景启动；
- 真实碰撞、触控延迟、完整高速跑局与按 seed 的引擎复现；
- OGG/WAV 实际听感、设备音频延迟、章节/BOSS 混音与恢复状态；
- 存档损坏后的设备端文件恢复、Android APK 导出/安装、FPS/温度/内存与持续运行。

项目当前没有 APK；Release 签名配置仍为空。不得将静态检查通过说成“实机通过”“帧率提升 X%”或“无 Bug”。
