# v2.9.0-G 统一修复报告

## 基线与边界

- 基线：v2.8.1-G / Android versionCode 23。
- 修复版：v2.9.0-G / Android versionCode 24。
- 当前执行环境没有 Godot 4.7.x、ADB 或 Android 导出工具。本文所列通过项来自 Python 离线检查与源代码契约，不应解释为引擎编译、游戏运行或真机验收。

## 本轮已修复

1. **DDA 类型契约**：将 `dda_enabled: bool` 与 `dda_mode: String` 分离，统一传给 Spawner、Game 和输入轨迹。
2. **回放兼容性**：引入 trace schema 2、ruleset 版本、游戏/引擎版本、物理 tick rate 和实际 DDA 模式；不兼容、截断或不可回放轨迹会拒绝启动。
3. **道具安全投放**：有限搜索三车道与多个纵深候选，最终写入前再次检查；无法找到安全点则跳过本次投放。
4. **音频总线与音效优先级**：将 Music、SFX、UI 分开；按声音重要程度管理 8 个播放器，低优先级音效不能抢占更重要的提示；统计被丢弃音效数。总线与效果初始化改为可复用已有总线/效果。
5. **进度持久化事务**：跑局统计、任务进度/完成、复活、超频、BOSS 奖励等采用快照回滚；任务/成就通知只在写盘成功后广播。MD5 校验仅用于发现意外损坏，不作为反作弊机制。
6. **输入队列溢出**：新增溢出计数并优先逐出车道微调；若队列只剩关键动作，保留固定容量限制并使用明确策略处理后续输入。
7. **独立离线契约**：新增 `tools/validate_v29_contracts.py`，同时修正旧生命周期检查器中的过期变量名/签名，避免校验器与源码基线脱节。
8. **模块边界**：新增 `Telemetry.configure_targets()` 与 `Effects.apply_perf_profile()`，去除 Main 对私有 `_apply_grade()` 的直接调用，以及 Telemetry 对 `_rain`/`_speed_lines` 私有节点的直接写入。
9. **进度事件热路径**：跳跃/滑铲只筛当前可递增的任务；任务无关事件立即返回；需要落盘时仅快照任务、成就与待发事件，不复制整份生命周期统计/设置/皮肤状态。
10. **版本与文档**：更新项目/Android 版本标识、当前 README、项目地图、开发指南和回归清单。

## 离线验证

- 9 个 GLB 模型、6 张 1024×1024 PBR 贴图通过资产检查。
- 55 处字面资源引用与 30 个唯一导入 UID 通过检查。
- 9 首 OGG 与 12 个 WAV 通过既有音频结构/波形契约；最终干净解压副本会再次执行完整音频解码。
- 模式目录：26 个模式、47 个障碍定义、24 条芯片线的结构检查通过。
- 16 个 GDScript 通过基础词法分隔符扫描和格式检查。
- DDA、schema 2 回放、道具候选安全、分离音频总线/优先级、事务通知、输入队列溢出、Telemetry 公共接口与任务进度窄快照等 v2.9 契约通过。
- 离线入口：`sh tools/run_offline_checks.sh`。系统有 Godot 时会追加 headless 导入和主场景冒烟测试；当前机器未安装 Godot，所以该步骤会标记为 SKIP。

## 尚未关闭的运行时验收项

- **G01**：Godot 4.7.x 语义编译、资源导入、Shader 编译和主场景启动。
- **G02**：同版本同 tick rate 下重复回放对照，验证物理/碰撞结果的一致性。
- **G03**：至少 100 个固定 seed 的高速跑局，检验跳跃、滑铲、碰撞盒、BOSS 和动态机制组合可解性。现有模式扫描仅排除部分结构性全车道封路。
- **G04**：混音听感、总线增益、限幅器在手机扬声器/耳机上的实际输出与失真风险。
- **G05**：Android 安装/后台恢复/存档恢复/连续运行/性能帧时间/温度。
- **G06**：正式导出签名、SDK/模板版本和 APK 安装签名。

## 发布结论

本轮源码修复和离线回归已完成，最终包需在干净目录复验。引擎编译、Android 导出与设备测试仍未执行，因此不能将本版本标记为完全通过发布验收。
