# 霓虹疾驰 2099 · v2.1.0-G 当前维护状态

## 维护原则

从用户给出的 `v2.0.0-G` 主线源码上累进升级，不推倒重来。优先修复可以从源码与数值模型证明的问题，保持已有玩法、资源和架构；未经 Godot/实机测量，不声称完成语义编译、帧率提升或无 Bug。

## v2.1.0-G 已完成

- 增加每局确定性随机种子，接入障碍、道具与 BOSS 波的玩法随机路径；修正 RNG 闭包状态不能依赖可变标量捕获的问题，改用共享数组保存状态，校准为标准 Mulberry32，并用 16 位拆乘实现无溢出依赖的 32 位 `imul`；固定 seed 参考向量锁定前几项输出，结算数据包含 seed，便于复现特定局。
- 背景音乐继续使用 9 首 OGG；短 SFX 改为 12 个离线生成 WAV 和 8 声道播放器池，消除未用实时合成器和单振荡器音效覆盖问题。
- 加固存档 guard 校验，先验证数据类型/范围再转换；拒绝整数域小数；默认设置 schema 添加 `hdr`。
- 收紧任务状态：进度/完成/领取状态只从当前已选任务加载，领取时二次确认 ID 仍在所选列表；每日任务只接受 3 个固定任务加 3 个每日任务的完整集合。
- 前轮修正持续保留：车道阻尼引导、连续输入合并、滑铲统计、商店/任务回调 ID、950m 高速时序及固定步长循环减分配。
- 把离线校验器扩展到音效映射、WAV 格式/时长、随机种子路径和 GDScript 词法结构。
- 更新工程/Android 版本标识至 `2.1.0-G` / `versionCode=15`。

## 当前离线验收

9 个 GLB、6 张 PBR 贴图、46 处字面资源引用、30 个唯一导入 UID、9 首 OGG、12 个 WAV、版本一致性、存档 guard、任务状态白名单、音频/随机种子/玩法源码契约以及 16 个 GDScript 文件的基础词法结构检查均通过；完整结果见 `ROUND_6_VERIFICATION.md`。
