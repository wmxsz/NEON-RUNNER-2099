# v4.3.0-G 综合升级审计：持久化安全、移动触控恢复与实体跑道细节

> 当前开发基线：v4.3.0-G（Android versionCode=39）。唯一源基线为用户提供的 v4.2.0-G 完整源码 ZIP；本版在其工作副本上进行成组修改。

## 本轮处理范围

本轮不把版本号、重复扫描或几个参数改动计作优化。经检查，原工程已经具备原生 PBR、程序天空、分档阴影/辉光、MultiMesh 城市、屏幕空间跑道抗锯齿，以及有限长度输入记录。因此优先处理跨组件的数据安全与恢复边界，并对近景跑道增加可见的实体几何细节。

### 1. 测试与正式玩家存档/回放隔离

- 发现原有三个模拟测试会直接删除 `user://nr2099_save.cfg`，却没有在所有 Godot runner 中统一启用已有的 `NR2099_TEST_MODE`。这可能损坏玩家正式进度；修复后，脚本测试与两个 shell runner 都强制启用测试模式。
- Progress 使用 `user://nr2099_test_save.cfg`；主场景的最后一局回放也改为 `user://nr2099_test_last_run_input_trace.json`。测试工件清理只针对测试命名空间及其 `.bak` / `.tmp` / `.corrupt` 侧文件。
- 原回放写入是直接覆盖 JSON；现在先写 `.tmp`、flush、重新读取并检查数据结构后才替换正式记录。已有目标文件会轮换到 `.bak`，新文件安装失败时尽力恢复；回放读取会分别完整校验主文件与备份文件。
- 新增运行时回归：写入两份合法记录，模拟主 JSON 损坏，确认读取器回退到上一份符合回放规则的备份。

### 2. 移动端触控生命周期

- 输入层现在在 `NOTIFICATION_APPLICATION_FOCUS_OUT`、`NOTIFICATION_APPLICATION_PAUSED` 或窗口失焦时清理队列及当前活动手指状态。即使系统切后台时没有发出最终 touch-up，也不会把旧手势带到下一次恢复。
- 新增机制测试验证活动触点、手势标志和排队动作均被重置。此项是源码与测试合同，Android 真机上的系统通知时序仍需实机验收。

### 3. 跑道实体硬表面细节

- 道路新增原生 `MultiMeshInstance3D` 横向装甲肋和钛合金紧固件：88 行横肋、528 个低面数紧固件；两类几何各自共享网格和材质，关闭额外投影。
- 道路长度与中心位置由同一组常量供跑面、边缘导轨和实体细节共同使用；横肋间距从当前道路 `road_cycle_length` 推导；8 行构成一次滚动周期，硬件根节点沿现有道路 shader 的距离参数同步运动，绕回时重置插值缓存。
- 理论上仅新增两个共享材质的绘制调用；实际 FPS、GPU 时间、发热和视觉效果未在本环境测量，不能把理论成本当作实机结果。

## 静态回归与交付验证

本次针对原始 v4.2.0-G ZIP 的压缩数据 CRC 检查通过；修改后先后重新运行完整静态门禁，最近一次工作树结果为退出码 0：

- `python3 -m py_compile tools/*.py`：通过。
- `sh tools/run_offline_checks.sh`：静态门禁通过。版本/Android 身份为 v4.3.0-G / `versionCode=39`；9 个 GLB 模型、6 张 PBR 贴图、78 条字面 `res://` 路径、104 个导入 UID 和 24 个脚本/着色器 UID 检查通过；43 份 Markdown 本地链接和 21 个 GDScript 词法扫描通过。
- 城市回收数值参考、跑道屏幕空间抗闪烁、PBR 通道、确定性障碍池、车道/冰面运动参考、相机 60/90/120Hz 波形参考、存档校验合同与新加的测试隔离/回放恢复/触控/道路实体细节合同均通过。
- Godot 运行门禁明确返回 `SKIP Godot runtime suite: 4.7.2-stable executable not found.`。这不是通过；GDScript 语义解析、场景/Shader 导入编译仍未执行。
- 交付包 `NEON_RUNNER_2099_v4.3.0-G_source.zip` 已通过 ZIP CRC 检查（336 个归档条目，无 APK）；已解压到全新目录并从该目录重跑 `sh tools/run_offline_checks.sh`，静态门禁退出码为 0，Godot 运行子项仍明确 `SKIP`（缺少引擎）。

静态门禁只证明源码/资源/清单合同、数值参考与词法结构，不证明实际画面质量或设备性能。

## 未完成的验证边界

当前执行环境没有可用的 Godot 4.7.2-stable 可执行文件、Android SDK/Gradle/ADB 工具链或连接的 Android 真机。因此本轮无法声称已完成：

- Godot 编辑器资源导入、GDScript 语义解析与 Shader 编译；
- 启动实际主场景并目视验证细节、曝光、材质和不同设备渲染；
- Android APK 导出/安装、触控中断实测、FPS/p95 帧时间/温度及长时间稳定性测试。

离线通过不等于上述任一项目通过。APK 仍未包含在源码交付内，也没有签名发布配置。
