# 更新日志

> 当前开发基线：v4.3.0-G（Android versionCode=39）。


## v4.3.0-G — 可靠回放事务、测试隔离、移动触控恢复与实体跑道装甲细节

- **存档/测试边界修复：**旧测试入口直接删除 `user://nr2099_save.cfg`，且 shell runner 未统一隔离；现在所有 Godot 测试入口启用 `NR2099_TEST_MODE=1`，清理只针对 `nr2099_test_save.cfg` 与测试回放文件。正式玩家存档/回放不作为测试夹具。
- **回放写入事务化：**记录先写 `.tmp`、flush 并从磁盘重新解析，再轮换 `.bak` 与正式记录；安装失败会尝试恢复旧记录。加载先验证主文件，再回退到 `.bak` 中通过完整 replay schema 校验的记录。新增主文件损坏后的备份恢复合同。
- **移动端输入中断修复：**应用失焦、暂停、窗口失焦时清除活动触点与队列，防止切后台时缺失 touch-up 事件，在恢复后制造意外跳跃/转向。
- **跑道实体细节：**以原生 MultiMesh 增加 88 组机械装甲横肋和 528 个低多边形钛合金紧固件，关闭其投影并共享两种材质；42m 滚动周期与现有 shader 完全同步，避免单体节点堆积和每帧逐个实例更新。
- **版本/验收边界：**版本为 `4.3.0-G` / Android `versionCode=39`。这一轮改动不仅更新版本；不过本环境缺少 Godot 执行文件，语义编译、实际渲染和 Android 真机性能仍未运行。

## v4.2.0-G — 原生渲染预算分层与赛博跑道抗闪烁升级

- **成批优化渲染管线：**将方向光阴影按设备档位分层：高档采用 Godot 原生 PSSM 四分区、60m 距离与柔和分区过渡；中档采用双分区、42m 距离；低档关闭方向光阴影。保留原生分辨率 1.0 与 4× MSAA，不通过模糊几何边缘降档。
- **真实辉光成本控制：**不再只调低/调高 Glow 总亮度，而是按设备档位分别配置五层、三层和零层常态辉光；低档超频只临时恢复两层局部辉光，避免把更宽、成本更高的模糊层级全部重新打开。
- **赛博跑道远景清晰度：**道路的装甲接缝、电路刻线、双侧能量导轨、中心导轨、同步脉冲与数据刻度使用基于 `fwidth()` 的屏幕空间覆盖率，降低远处细线路闪烁/断裂。没有增加纹理采样，没有降低 3D 分辨率或关闭抗锯齿。
- **运行时诊断增强：**遥测快照增加实际生效的阴影模式、阴影距离、辉光层级与超频状态，便于后续设备日志确认降档是否真正执行。
- **测试联动：**机制测试逐档验证高/中/低阴影配置、辉光层数与低档超频恢复；离线合同检查原生 API 接线、道路导数抗锯齿以及渲染预算遥测。
- **版本/验收边界：**版本为 `4.2.0-G` / Android `versionCode=38`。离线门禁和 ZIP 干净解压复验属于静态验收；当前环境没有 Godot 4.7.2-stable 可执行文件，因此引擎语义编译、着色器实际编译、画面录制及 Android FPS/p95/温度仍未完成。


## v4.1.0-G — 确定性测试与 PBR 材质保真升级

- **清除常量真值测试：**将 runtime 的结算 UI 检查从无条件通过改成核对结算面板可见、距离前缀与实际分数；content 的输入队列测试改成核对队列确实为空且清队列后不会触发跳跃。发布门禁新增 `_ok(true, ...)` / `assert(true)` 检查。
- **激光机制测试去随机化：**将激光章节测试从一次性随机命中率对比，改为确定性候选池权重检查，精确验证激光模式按 3× 权重重复入池、非激光候选数量不变。配置从 `3.4` 规范为 `3.0`；旧实现已通过 `int()` 截断为 3，因此实际候选池及 RNG 消耗不变。
- **PBR 粗糙度保真：**导入 GLB 材质只在原材质没有 roughness texture 时补充共享微粗糙度，不覆盖外部/未来模型自带的粗糙度贴图。
- **headless 音频一致性：**`run_tests.sh` 使用 `--audio-driver Dummy`，避免无声卡环境的驱动差异影响逻辑测试。
- **验收范围：**源码、资源、确定性测试合同与最终 ZIP 干净解压检查通过；Godot 4.7.2-stable 语义编译、Shader 导入、实际画面/Android FPS 仍未运行。

## v4.0.0-G — 原生赛博天空与真实测试门禁修正

- **环境视觉升级：**将原先单色 `Environment.BG_COLOR` 背景改为 Godot 原生 `Sky` + `ProceduralSkyMaterial`。天空顶部采用深墨蓝，天际线过渡到紫红，地平下沿使用冷青；开启去色带，缩短太阳圆盘为不可见状态，避免出现不符合赛博城市构图的大太阳。
- **移动端反射预算：**原生天空 radiance 尺寸限制为 128×128，并使用 `Sky.PROCESS_MODE_INCREMENTAL`，避免首次启动进行长时间的一次性辐射图烘焙。天空保持静态，章节过渡通过雾色、环境光、建筑电力脊线、网格背景和跑道霓虹持续表达，避免 30Hz 主题更新反复失效天空辐射缓存。
- **修正测试执行器异步缺陷：**`tests/test_headless.gd` 原先调用含 `await` 的 `_run_all()` 却没有 `await`，运行可能在第一个挂起点之前就打印结果并退出。现在先等待所有断言完成，再根据最终失败数退出。
- **移除虚假通过条件：**删除 headless 与 content 测试中的 `or true` 弱断言，改为校验测试模式查询返回布尔值，以及遥测的公共信号/性能档位。
- **修正 soak 测试预算：**`test_content` 包含 25 秒长跑、可能的 BOSS 验证、复活倒计时与后续回归，原 1800 帧上限在 60 FPS 下只有约 30 秒，存在提前终止测试的风险；单独提高到 5400 帧，并统一以 `--fixed-fps 60` 运行 headless 测试场景与主场景冒烟测试。
- **新增天空行为测试与门禁：**机制测试检查正在使用的 `WorldEnvironment`、`BG_SKY`、`ProceduralSkyMaterial`、128 radiance 与 incremental 模式；离线合同会拒绝天空配置意外回退或测试断言出现始终为真的表达式。
- **版本/验收边界：**项目升至 `4.0.0-G` / Android `versionCode=36`。离线源码/资源/文档合同通过后才能交付；Godot 4.7.2-stable 实际语义编译、渲染画面、启动耗时与 Android FPS/p95 仍需要在具备引擎和设备的环境验收。

## v3.5.0-G — Godot 原生渲染/插值纠正与全项目审计

- **原生物理插值启用：**在 `project.godot` 的 `[physics]` 中启用 `common/physics_interpolation=true`，保留 60 Hz 固定模拟和 60/90/120 FPS 渲染目标。Player 的整姿态复位之后重置插值历史；建筑根/远景根重新基准、地标/飞行器/霓虹标牌/拱门回收，以及冲击波、碎片、尾迹和 MultiMesh 池对象初始激活/隐藏都执行恰当的 `reset_physics_interpolation()` 或 `MultiMesh.reset_instance_physics_interpolation()`，避免跨大距离插值拖影。
- **相机与 UI 分工清晰：**相机继续使用 `_process()` 的逐渲染帧阻尼跟随和 `look_at`，显式关闭它自身的原生物理插值，避免两套平滑叠加；HUD、菜单及屏幕效果层也不参与物理变换插值。
- **原生优先的后处理：**正常游玩时不显示含 `hint_screen_texture` 的全屏后处理层，所以不再每帧触发屏幕纹理复制、4 邻域锐化、重复对比度/饱和度调整及色彩分级。原生 `Environment` 继续负责 Filmic tonemapping、环境光、雾和 Glow；原生 4× MSAA、16× 各向异性过滤、PBR `StandardMaterial3D`、`GPUParticles3D`、AudioServer 总线、原生 Control/StyleBox 与 Tween 保留。色差只在速度超过阈值/超频时作为赛博冲刺强调显示，绘制时只需中心与两个色差偏移采样。
- **MultiMesh 池插值修复：**活动障碍/芯片/道具继续在物理 tick 之间使用 Godot 原生实例插值；只在隐藏或新对象激活时对对应实例重置插值状态。修正道具多部件共用可见状态标记的时序，确保所有零件一起初始化、一起隐藏，不让第二部件沿用默认原点变换。
- **全面复查的二次修复：**又补齐建筑天线/顶部/屋顶单元的回收插值复位，以及地标、飞行器、标牌、拱门和初始 MultiMesh 缓冲的首次摆放复位，避免装饰从旧位姿拉出残影。
- **高刷 Shader 同步：**Godot 不会自动插值 Shader uniform，本版在渲染循环中使用原生 `Engine.get_physics_interpolation_fraction()` 插值跑道 `scroll` 与建筑窗格 `time_`。正常场景动画可跟随渲染频率；暂停/结算/复活等待态冻结到最新模拟值，周期滚动使用正模数防止跨边界倒跳。
- **全面项目审计：**逐类复核场景、GLB、PBR、赛博跑道/窗格 Shader、Environment/灯光、Particles、HUD/菜单、音频混音、存档、回放、生命周期与移动端设置。明确保留固定时步车道跑酷运动与回放逻辑，不强行改成基于碰撞求解的 CharacterBody3D；已有原生功能工作正常时不为了“更原生”强行重写，赛博风格保留在自定义模型、材质、能量线路与有条件的专用 Shader 中。
- **验证/发布：**版本为 `3.5.0-G` / Android `versionCode=31`；新增原生功能、初始姿态、装饰插值复位、Shader 渲染时间同步和可移植测试入口源码合同。工作目录检查通过，完整 ZIP 已在全新解压目录复跑离线门禁并通过。当前环境无 Godot 4.7.2-stable 可执行文件，故 GDScript 语义编译、Shader 导入、画面录屏、Android FPS/p95/温度、APK 导出尚未运行。

## v3.4.0-G — 全赛博风格材质与未来跑道视觉升级

- **艺术方向深化：**道路资源正式采用 `cyber_deck_*`，以赛博能量跑道、碳陶复合装甲模块、霓虹导轨与数据脉冲作为统一设计语言。
- **跑道 PBR 深化：**生成 1024×1024 装甲板 albedo、normal 与线性 roughness；增加双层精密边框、四点数据锁、遥测刻线、接口环和清楚的机械倒角。提高装甲板本体可读性，减少随机颗粒噪声占比。粗糙度 Alpha 与独立可编辑灰度源图逐像素一致。
- **赛道着色器：**使用两次纹理读取；叠加动态能量导轨、主题色分段电路、中心同步标记和远景细节衰减，保留原生渲染比例/4× MSAA，没有通过降低清晰度实现性能目标。
- **机甲与载具表面：**`cyber_armor_*` 升级为近中性高亮底层的双切面六角陶瓷复合装甲、内嵌遥测刻线和精密触点；避免旧灰度贴图乘算时压暗 GLB 原色，保留阵营/章节色和发光区域。
- **数据拱门模型：**将过厚的单环改为薄型主题主环、独立青/洋红能量导管和 8 个批处理识别刻度；取消阴影投射、保留独立淡出，提升结构层次且不额外创建 8 个节点。
- **PBR 与光泽层次：**碳陶面板恢复合理漫反射，抛光能量导轨才采用更高金属度/更低粗糙度；不再让整条赛道全部呈现相近的金属响应。
- **城市建筑：**共享窗格着色器增加分段电力脊线和细窄主题色能量通道；复用既有实例种子/窗格变化值，不增加贴图读取或额外灯光节点。
- **资源/验证/版本：**同步更新资源路径、导入 sidecar、生成器、质量合同和美术管线文档；版本升至 `3.4.0-G` / Android `versionCode=30`。离线 PBR/资源/模型/源码合同通过；Godot 着色器编译与 Android 实机视觉/FPS 尚未运行。

## v3.3.0-G — 道路 PBR 与城市/特效更新成本优化

- **道路 PBR：**albedo RGB 与 roughness 线性值打包进同一 RGBA 贴图，独立 roughness 源图保留；道路 Shader 每个片元的纹理采样从 3 次降为 2 次。Alpha 与源图像素精确匹配，仍为 1024×1024。
- **窗格 Shader：**将窗格随机/闪烁/招牌故障计算限制在侧墙和细节足够可见的区域，复用随机值，保留玻璃高光与霓虹窗格表现。
- **近远景城市：**近景 96 栋和远景 80 栋楼体改为按回收深度排序的事件队列，普通帧不再扫描每个实例；近景直接构建回收变换，减少多余变换读取，保留屋顶和檐线同步回收。两个 12,000 帧数学模拟最大坐标偏差均约为 `10^-12` 米量级。
- **特效池：**碎片和尾迹改为仅更新活跃槽位；雨粒子停用时跳过密度计算，活跃时按变化阈值更新。城市标牌轨道材质与地标缩放只在实际值变化时写入。
- **FPS 预算：**`qualityBudgetMultiplier` 从 1.75 调整为 1.25，维持 2 秒采样窗口与双窗口迟滞；目的是更早发现持续低于目标刷新率的情况。没有降低原生分辨率或关闭 4× MSAA。需实机确认不会过早降档。
- **发布与验证：**版本升至 `3.3.0-G` / Android `versionCode=29`；离线门禁新增 roughness Alpha 像素一致性、近景/远景事件队列模拟及材质更新门控。Godot 语义编译、Shader 实际编译和 Android FPS/温度仍未在当前环境运行。

## v3.2.0-G — 深度视觉与帧预算优化

- **全屏后处理成本：**常态关闭色差时不再读取红/蓝偏移采样，屏幕纹理读取由常态 7 次降至 5 次；胶片颗粒与扫描线关闭时跳过对应逐像素计算，并移除不再需要的每帧时间 uniform 上传。锐化与原生 3D 渲染比例保留。
- **窗格 Shader：**复用同一窗格的随机值，程序化 hash 调用点从 8 处降至 4 处（helper 定义另计），保留窗框、高光与偶发故障效果。
- **城市滚动：**近景楼群、屋顶装饰与远景楼群使用父节点位移及缓存本地 Z；正常帧不逐个重写 MultiMesh 变换，只有物件回收或周期重定位才写入实例缓冲。12,000 帧数值对比中，算法模拟世界坐标最大漂移为 0。
- **画面稳定性与画质：**性能降档时仍保留原生比例和 4× MSAA，不通过降低渲染比例换帧率；性能压力先由 Bloom、阴影与粒子预算承担。
- **Bloom 真降本：**低档性能预算时禁用多层辉光合成器，而不是只调低辉光强度；短时超频会恢复辉光提示，结束后回到设备档位策略。
- **模型网格质量护栏：**额外验证退化三角面、重复面、非有限面积和非有限法线；当前 9 个 GLB 均无退化/重复面。
- **回归与诚实验收：**更新缓存坐标、Bloom 与 Shader 成本的源码合同；版本升为 `3.2.0-G` / Android `versionCode=28`。离线检查不能证明实际 GPU 帧率变快，Godot 语义编译、渲染截图与 Android 真机帧时间仍未在当前环境运行。

## v3.1.0-G — 画面清晰度、曲面建模与 PBR 质感升级

- **输出清晰度：**默认 MSAA 从 2× 提升至 4×、各向异性过滤从 4× 提升至 16×，保持 3D 渲染比例 1.0。
- **后处理：**增加低强度边缘门控锐化与温和对比度/饱和度控制；降低颗粒和暗角，色差仅在高速/超频时轻微增强，HUD 仍在后处理层之后绘制。
- **道路材质：**复用现有 PBR 贴图增加湿润区域高光与轮迹磨耗变化，不添加额外运行时灯光或贴图采样。
- **城市与窗格：**建筑窗户增加内嵌边框与受控玻璃高光，建筑从 88 栋增至 96 栋、远景轮廓从 64 增至 80 栋，仍按 MultiMesh 分组。
- **建模与材质：**提高玩家球面/胶囊/圆环细分；GLB 生成器将椭球最低细分提升至 3；交通模型、地标和 BOSS 面数上升，材质批次仍保持合并。
- **PBR 贴图：**重新生成装甲与道路基础 albedo/normal/roughness，强化微划痕、粗糙度变化与法线细节，继续保持 1024×1024 且通过接缝检查。
- **版本与验收：**版本升至 `3.1.0-G`、Android `versionCode=27`，所有活跃基线与审计指针同步。离线检查不会替代 Godot 4.7.2-stable 导入/着色器编译及 Android 真机测试。
